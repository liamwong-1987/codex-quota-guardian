# Codex 额度守护者

> 先想清楚，再开始做；把额度花在真正影响质量的地方。

OpenAI Codex 平台的 **额度守护者** Skill：通过单主智能体模拟的**五职业评审**、**结构化头脑风暴**、**单执行者模型选择**和**可验证执行**，在质量优先的前提下减少返工与额度浪费。

---

## 适用场景

- 新项目、新功能、结构性变化、重要决策
- 复杂研究、内容策划、方向不明确
- 返工代价高的修改

简单问答、翻译、错别字等边界明确的小操作不触发完整流程。

---

## 核心机制

| 机制 | 作用 |
|------|------|
| **五职业评审团** | 由当前主智能体模拟五位不同职业的专家独立判断、交叉质疑、主负责人裁决 |
| **结构化头脑风暴** | 用弹窗集中确认关键决定，不反复追问 |
| **Sol / Terra / Luna 模型调度** | 三档模型等级，按任务复杂度推荐 |
| **额度保护** | 不重复、不乱试、不换模型，完成就停 |
| **小步执行 + 真实验收** | 依赖顺序推进，每步用真实证据验收 |

---

## 三档模型等级

- **Sol（总负责人）**：方向和结构不明确、跨模块、高风险或失败代价高的工作
- **Terra（主力执行者）**：方案已确认、需理解上下文、处理常规异常
- **Luna（快速助手）**：范围窄、规则明确、容易验证和恢复的小任务

---

## 完整流程

1. **判断方向**——五职业评审团达成共识与裁决
2. **确认方案**——结构化弹窗集中确认 3-4 个关键问题
3. **推荐模型并保护额度**——为每个任务写模型卡（推荐模型、推理强度、理由、升级条件）
4. **执行与交付**——按小步推进、用真实证据验收
